# 将酶设计知识用于 Gaussian TS 研究

本文件是既有路线资料与当前工具包的衔接说明。它不引入新工具，不把文献中的成功率或筛选阈值转换为本项目的科学验证规则。

## 先选择任务入口

| 当前起点 | 知识库中的可选路线 | Gaussian 在其中的作用 |
| --- | --- | --- |
| 目标反应明确，催化几何待建立 | Theozyme、RFD2 原子级构建、RFD3 条件生成 | 拆解基元步骤、比较催化假设、建立和验证局部反应模型 |
| 已有催化 motif 或骨架库 | RFD motif scaffolding、Theozyme/RIF 匹配 | 检查关键状态和几何的物理依据；不强制重做已有可靠证据 |
| 已有活性亲本 | 底物逐步适配、局部 RFD 改建、ML 辅助进化 | 在化学步骤可能受限时检验机理；表达、稳定性问题优先对应路线 |
| 有功能家族或系统发育信息 | 家族序列生成、祖先重建、稳定性工程 | 按研究问题补充化学分析，不把 TS 搜索作为所有路线的前置步骤 |
| 需要人工辅因子或非天然催化基团 | 人工金属酶、非天然氨基酸催化 | 明确组分、电子态和模型边界，区分游离辅因子与蛋白环境效应 |

具体研究 ID 和适用限制见 [route_selection.json](route_selection.json)。选路是综合判断；RFD2、RFD3 和亲本改建的结果不可直接当作同一种独立从头设计成功率。

## 在当前接口记录研究条件

沿用 [Codex 使用说明](../CODEX_GUIDE.md) 的 `problem.json`：

- `question`：本次要解释或验证的基元步骤，以及它在整个催化循环中的位置。
- `fixed_conditions`：用户已明确的底物/产物、模型组分、边界、电荷/自旋、计算水平和资源限制。
- `hypotheses`：催化残基角色、质子化、配位及可能路径；每条注明来源 ID 或“综合推断”，不冒充已验证事实。
- `uncertainties`：缺失映射、原子来源、电子态、溶剂/水、构象、参考态或尚待核查的文献参数。
- `notes`：选路理由、来源文件、版本、核查范围和计划向下游交付的内容。

这是现有问题定义字段的填写指导，不是新的 reaction.json schema。稳定原子 ID、成断键、charge、multiplicity、job_defaults、limits 等可执行配置仍遵循 [工具 API](../API.md)；历史方案中的 `reaction.yaml`、`campaign.yaml` 等只是未来交接约定，当前 CLI 不会直接读取它们。

## 化学模型与验证

先检查反应计量、元素和电荷、原子映射、立体化学及必要共反应物。底物/产物不能唯一决定催化残基；每套机理与质子化假设独立登记。完整游离氨基酸与截断侧链模型各有适用范围：前者应检查端基是否主导反应，后者应记录断口补氢和环境近似。采用本次明确的模型条件。

摆放与 frozen_opt 用于建立预组织初猜；松弛扫描峰用于挑选后续 TS 初猜，均不等于目标 TS。金属体系要持续检查供体身份、配位数、质子归属及电子态，不能只监测反应键。

工具动作、结构与父作业关联严格按当前 schema 执行。历史文档提及的 NoEigenTest、原生 checkpoint 续算、电子稳定性检查等不表示现有类型化 API 已支持；本工具包当前不提供 NoEigenTest。需要额外功能时，明确区分独立计算证据和已被验证器接纳的证据。

只有真实证据经 `verify_ts` 返回 `VALIDATED_TS` 才能报告已验证目标 TS；单虚频、正常结束、冻结优化或人工修改标签都不能替代。若涉及外围冻结、电子分支变化或当前端点规则不适配，保留不确定状态并说明缺失证据。历史 V1 中的小写 `validated_ts` 是方案状态名称，不是绕过当前验证器的成功入口。

## 交接到蛋白设计

Gaussian 工具包负责计算和证据；RFD、MPNN、Rosetta、结构回预测和 PLACER 是后续独立环节。后续实现的 [酶设计工具接口](../ENZYME_DESIGN.md)可通过独立 campaign 执行这些阶段；它有独立输入契约、环境配置和预算，不自动执行历史 V1 配置，也不改变 Gaussian 的验证规则。

| 交接内容 | 必须包含的依据 |
| --- | --- |
| 反应与状态定义 | 底物/产物、目标步骤、各中间体/类似物的连接、手性、电荷与质子化 |
| Theozyme 几何 | 结构坐标、催化功能原子、必要金属/水、模型边界、实际验证状态 |
| 原子及残基映射 | 稳定 QM 原子 ID 到配体/残基名的映射；截断恢复说明，不能仅凭距离猜残基 |
| 约束与可设计范围 | 保留原子、距离/角度、残基与主链贡献、允许调整区域、约束来源 |
| 证据与出处 | 原始输入输出、频率/IRC/端点、计算水平、哈希、验证报告、失败与未检验项 |
| 下游评估计划 | 按反应选择的状态、底物通道、第二配位层、多样性、实验对照和反馈字段 |

PDB/CIF 和下游约束文件需要另行生成并核对；不能把 QM 中部分成断键或金属配位无条件当作普通稳定小分子参数化。低自由能反应物构象也不能直接改称过渡态。若仅使用假设 motif 进行探索，交接中必须保留假设标签。

RFD3 文献的 ES/AEI/TI1/TI2 四状态属于特定共价水解机理，不应机械移植到金属催化等体系。各路线分别评估全局折叠、局部催化几何、配体位置、相关状态、通道和表达；几何/置信度/PLACER 构象比例不是自由能势垒、kcat 或催化活性的直接证据。

## 结果与下一轮

分别统计生成骨架、设计序列、订购、实际测试、可溶表达、探针反应、单次反应、持续周转及动力学；亲本重设计与新骨架分开。E006/E015 共享金属水解酶实验不能重复计数。来源快照中尚未完成补充材料完整审计或独立复现的内容继续标为待核查。

表达失败先查折叠与构建；表达正常无反应则查化学假设、底物可达性与检测；出现爆发后停止则查中间体、产物释放与失活。单步 TS 通过只支持所用模型中的该步骤；整体催化循环、实验活性和可用蛋白仍需各自证据。修改研究范围和预算时保留原结果及决策依据。
