# 酶设计路线与 RFD 实用指南

本指南用于从目标反应选择设计路线，并为计算与实验建立可追溯的交接条件。RFD 是重点；已有亲本、天然序列家族和人工辅因子路线仍保留。以下路线选择与交接要求是基于来源的综合判断，具体论文的数字和核查范围见来源登记。

## 根据起点选择路线

| 已有条件与目标 | 建议优先考虑 | 进入下一步所需证据 |
| --- | --- | --- |
| 只有目标反应与可辩护的催化几何 | RFD2 原子级活性位点构建，或 RFD3 条件生成 | 反应物、产物、催化基团、配体和反应状态有一致映射 |
| 已知催化残基的主链布局 | RFD motif scaffolding | 局部主链与催化侧链同时可实现 |
| 已有活性亲本但局部几何受限 | RFD 局部改建或局部重设计 | 亲本基线、限制环节及可保留区域 |
| 有合适口袋的折叠家族，天然骨架不够多 | 生成骨架库后做 RIF 匹配 | 折叠家族可容纳底物与催化配置 |
| 有骨架库与成熟催化几何 | Theozyme 与骨架匹配 | 匹配后仍保留必要接触和底物通道 |
| 有可靠的序列与活性测量 | 定向进化及机器学习辅助进化 | 可重复测定、训练覆盖与独立留出评估 |
| 已有目标活性，但表达或稳定性不足 | PROSS 类稳定性设计 | 优化后重新测量活性，避免只比较表达量 |
| 亲本支持目标化学，但不接受目标底物 | 底物逐步适配与亲本改造，再定向进化 | 先获得可确认的目标底物活性，再优化工艺条件 |
| 有天然功能家族，希望扩展序列空间 | 家族语言模型生成或祖先重建 | 新序列的目标产物、活性与稳定性测定 |
| 非天然辅因子支持目标化学 | 人工辅因子酶与进化 | 装载量、游离辅因子及蛋白本身的对照 |

稳定性、表达、结合与催化是不同优化目标。只有新增目标反应的产物与周转证据，才能把结果归为新的催化功能。

## RFD 版本与证据的对应

RFD1 丝氨酸水解酶研究显示，探针反应或底物单次酰化可以出现，却不一定有持续周转。因此，设计共价催化循环时，应同时考虑酰化与脱酰化，而非仅让亲核基团靠近底物。[丝氨酸水解酶研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC12288761/)

RFD2 从功能原子的几何出发，让模型选择残基在序列中的位置及相应侧链构象。其 AME 基准的41/41是计算构建结果；计算成功不能等同于41种酶的实验活性。金属水解酶实验与伴随论文存在共享数据，应按实验批次去重。[RFD2方法](https://www.nature.com/articles/s41592-025-02975-x)、[金属水解酶](https://www.nature.com/articles/s41586-025-09746-w)

RFD3 半胱氨酸水解酶案例使用催化模型、底物暴露度条件、序列与结构迭代及多个反应状态筛选。将它移植到其他机理时，应重新定义状态和接触，而非复制该水解循环。当前登记依据是2025年11月19日的预印本版本。[RFD3研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC12458353/)

这些研究改变了模型、催化模型、底物、筛选与实验条件，不能据各自命中率直接排列 RFD1、RFD2、RFD3 的优劣。

## 启动一个设计项目需要保存什么

1. **目标定义**：反应物和目标产物的带映射结构、立体化学、目标条件、检测方式，以及与亲本比较的指标。
2. **化学假设**：催化残基、辅因子、质子化、电荷、可能反应状态与竞争路径。区分天然结构提取的几何和量子化学得到的几何。
3. **模型输入**：固定原子及残基标识、配体键级和共价连接、可变区域、暴露度要求、原子顺序转换表。
4. **可复现记录**：代码提交、权重版本、配置、随机种子、输入哈希、环境依赖及每一步输出位置。
5. **候选台账**：为骨架、序列和重设计亲本分别编号，保存淘汰原因；不要只保留最终入选结果。

RFD3 原文中的部分原子命名和采样数存在待核对之处，具体见 rfd3_workflow.json。真实输入文件及代码应作为执行前的核对对象，不应从文字直接臆造原子映射。

## 从生成到实验的交接

生成之后先核查几何与化学一致性，再进行序列设计和结构回预测。回预测应检查催化位点、配体姿态与手性，而不只是全局折叠置信度。多状态计算用于发现某个步骤能被支持、另一个步骤却无法完成的候选；预测构象比例不能直接当作平衡概率或活化自由能。

入选实验时同时保留若干骨架家族，避免所有候选集中在单一结构。排名只对明确的指标负责，例如催化接触、配体位置或预测置信度；不要把复合分数解释为预测的催化速率。

金属催化候选还需检查供体原子、金属占有、竞争配位及非预期金属结合位点。模型中的理想配位与实验中实际配位需分别记录。

## 实验结果如何支持设计结论

| 观察 | 可以支持 | 还不能单独支持 |
| --- | --- | --- |
| 可溶表达或稳定折叠 | 候选具备可测量的蛋白基础 | 目标催化反应 |
| 探针标记、共价中间体 | 活性位点可发生相关化学步骤 | 催化循环可持续完成 |
| 超过空白的报告信号 | 候选值得进一步表征 | 正确产物、周转数或内在速率 |
| 产物确认与超过酶计量的形成 | 支持催化及多次周转 | 全部机理细节 |
| 纯化蛋白的浓度依赖动力学 | 条件明确的速率和效率 | 工业可用性或其他底物通用性 |

实验计划应预先区分技术重复与独立表达或纯化重复；根据体系安排无酶、失活位点、无辅因子和游离辅因子等对照。检测信号应转换到产物浓度，并注明背景处理、拟合区间和失活现象。低Km不能自动解释为高结合亲和力，尤其是在有共价中间体的机理中。

## 失败之后如何决定下一轮

- **表达失败**：先定位折叠、可溶性或构建问题；尚不能否定化学机理。
- **表达正常但没有反应**：检查底物进入、催化状态、检测灵敏度和化学假设，再决定是否重建活性位点。
- **有初始爆发但很快停止**：检查产物释放、脱酰化及不可逆修饰；不把一次反应报告为稳态周转。
- **有活性但离散性很大**：核对蛋白浓度、辅因子占有和背景，再做序列学习。
- **多轮没有改善**：比较每轮改变的假设和新增证据；若只是重复相同筛选，转向可区分失败原因的实验或计算。

这些是后续项目的判断规则，不代表对任何具体失败机制的预判。

## 如何比较研究

同时保存生成骨架数、设计序列数、订购数、实际覆盖数、可溶表达数和各活性标准下的命中数。混合文库的订购规模不等于每条成员均被测试。亲本的局部改建与完全新骨架也应分开。

动力学记录至少包括底物、温度、pH、溶剂、酶与辅因子浓度、单位和误差定义。kcat、kcat/Km、光强、终点转化率、酰化步骤速率各自回答不同问题，不能直接互换。初始设计与进化后最优变体分列；例如 LuxSit-i 的优化后性能不能归给最初的计算设计。[荧光素酶研究](https://www.nature.com/articles/s41586-023-05696-3)

## 天然酶底物适配案例

西格列汀转氨酶研究先用底物逐步适配、建模和突变建立微弱目标活性，再通过定向进化改善制造适用性。该路线适合已有催化化学、缺少目标底物适配的起点。[原始论文摘要](https://pubmed.ncbi.nlm.nih.gov/20558668/)

EPA奖项记录报告了工艺生产率、收率和废物的改善；这些属于工艺指标，不能解释为酶的kcat提升。该记录描述2009年中试和当时的商业化计划，也不能单独证明当前生产部署。[官方奖项记录](https://www.epa.gov/greenchemistry/presidential-green-chemistry-challenge-2010-greener-reaction-conditions-award)

## 家族语言模型的验证范围

ProGen的溶菌酶生成有新湿实验支持；其chorismate mutase和malate dehydrogenase功能预测使用既有实验数据，不能重复计为新生成序列的实验成功。该研究没有对未经家族微调的生成序列进行实验验证。因此，选择此路线时应首先确认有足够的相关家族数据，并保留独立实验评价。[作者稿正文](https://pmc.ncbi.nlm.nih.gov/articles/PMC10400306/)

## 祖先重建与共识设计的选择

祖先重建需要同源序列、比对和系统发育推断；共识设计通常从序列频率出发，两者不能作为同一个算法记录。建议保存祖先节点和不确定位置的替代候选，并与现生参照酶在相同条件下分别测量稳定性和活性。

Gumulya等的作者团队摘要报告了P450与KARI的实验案例，支持祖先重建可以提供兼顾功能和耐受性的候选，但不能推广为所有祖先都更稳定或具有新反应。论文报告的热失活指标不能换写成熔解温度，比活性也不能换写成kcat/Km；采用具体数字前仍需核对正文测定定义。[作者团队摘要](https://bodenlab.github.io/GRASP-suite/publication/engineering_highly_functional/)

## 复用已发表代码前的更正检查

PROSS的2018年更正补回了原补充脚本design.xml遗漏的参数，并移除无用文件；该更正没有修订实验测量结果。后续复用应选择更正后的补充脚本，并独立验证运行。论文方法、下载包和当前服务器实现应分别记录版本。[更正原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC5919778/)
