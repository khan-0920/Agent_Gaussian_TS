## 酶设计知识入口

涉及从反应构建催化位点或向蛋白设计交接时，先读[酶设计上下文](enzyme_design_context/README.md)与[项目衔接说明](enzyme_design_context/AGENT_INTEGRATION.md)，按当前问题选择路线并记录研究来源。已有活性亲本、序列家族与从头设计采用不同入口；不要把历史 V1 的完整残基、无水或预算设置当作本次默认条件。以下研究指导中的高级 Gaussian 功能仍以当前工具 schema 为准；本工具包不提供 NoEigenTest 或原生 checkpoint 续算入口。

## 1. 状态与模型

先读最新状态、session、原始日志、既往决策和进程，防止重复提交；实际状态优先于旧提示。建立 model.json/problem.json，记录稳定原子ID、元素、片段、残基命名、金属供体、反应键、质子归属、电荷/自旋、截断及物理假设。去主链后明确断口补氢，检查碰撞、价态和电子数，避免意外自由基。

保留初始XYZ、坐标构建脚本与摆放参数。每次作业新建目录，保存输入、输出、checkpoint、来源SHA256。更新status.json并追加history.jsonl：检查证据、决策、作业路径、待办、验证状态。原始失败日志不得覆盖。

## 2. 摆放 → Frozen Opt → 扫描

依据机制摆放催化组分，记录距离、角度、进攻方向和配位。冻结少量关键内坐标做局部优化消除碰撞；说明约束理由，逐步释放，不能把冻结结构直接当实际TS。独立优化反应物复合物，检查频率极小值及必要的电子稳定性。

选择机制相关的松弛扫描坐标；成键与质子转移耦合时必要用二维/分段扫描。峰附近细化。逐点核查收敛、构象变化、全部金属配位及质子归属。扫描峰只是TS初猜，扫描电子能差不是活化自由能。保存扫描点及其约束、实际距离和能量。

## 3. 无约束TS与频率

由合理扫描峰或QST2/QST3初猜做无约束TS优化。失败后依据日志调整初猜、步长、Hessian重算或数值精度，不盲目重复。

必要时可用Opt=(TS,CalcFC,NoEigenTest,...)容忍中途多个负特征值；它不保证沿正确模式，也不豁免最终一阶鞍点验证。具体语法及工具支持须核查。

严格核对最大力、RMS力、最大位移、RMS位移四项。正常结束或“力可忽略”不等于四项都通过；不满足时精修，不放宽阈值。最终结构做完整频率：非线性N原子应有3N−6模（线性另行处理），恰好一个有意义虚频，位移确实对应目标成断键及相关质子运动。导出位移模式并检查内坐标投影；单一键投影高分不能独立证明机理。额外虚频须诊断和重算，不能删去。

## 4. IRC、端点与独立参考

从同一个已收敛TS/Hessian做双向IRC。正/反向只是数学标签，要由结构识别反应物侧。到达点数上限或超时不代表到达极小值。必要时用完整checkpoint原生IRC Restart续算；最后坐标新起计算不能冒充同一条IRC续算。

续算前复制不可变checkpoint，记录父作业、源日志/检查点hash、方向和参数，核对点号、重叠几何/能量及最终终止原因。原超时作业仍标超时，不篡改成功。

两端均无约束优化并做完整频率，核对连通性、质子归属、金属配位、原子映射和电荷/自旋守恒。独立参考须由预先构建反应物或预IRC的受限产物构型单独优化；不得把IRC端点复制改名当参考。比较距离矩阵、关键键长、连通性、质子位置及能量；对称置换需明确映射，不为通过而调阈值。几何匹配不能替代频率和电子态验证。

电环化等反应需沿双向IRC跟踪明确的端基二面角、观察轴和对应原子，统一符号并展开角度，排除整体转动/坐标翻转；结合TS模式判断顺转/对转，不能只凭一张结构或任意视角。

## 5. 电子态

对TS、端点、独立参考按需要做Stable=Opt。固定核几何得到稳定波函数，不等于该波函数下几何已经优化。

若R→U不稳定，即使能差很小也记录。保留Stable=Opt后的U checkpoint，使用对应U方法及Guess=Read/Geom=AllCheck继续核优化，再做频率和稳定性。Guess=Mix可能坍缩回限制性解；检查实际SCF方法、S²、能量和来源。破缺对称单重态不是纯自旋本征态，报告自旋污染及适用范围。

限制性IRC接到稳定U端点时须核查电子分支衔接，必要时检查沿途稳定性、U路径或局部势能面。未解决时写明“几何路径建立，电子分支尚未验证”。不同自旋面、强多参考特征或金属态排序需额外研究，不能把任何收敛解当可靠基态。

## 6. 工程验证与结论

工具ok、job completed、Normal termination、单虚频与科学VALIDATED_TS不是同一层级。Reaction(st,st)占位不可用于最终目标验证。原生续算证据不能假定已经被session验证器接纳。需要时扩展验证器并测试；只有真实证据经项目验证器通过才标VALIDATED_TS，不手写成功状态代替。

解析器与日志不符时保留原文，定位格式差异，以真实片段建立回归测试，再修复重解析；不改原始输出或放松科学门槛。先查当前schema，不假设本prompt中的Gaussian功能都有现成类型化API。

以一致水平、温度和标准态报告相对反应物复合物的ΔE‡/ΔH‡/ΔG‡及RRHO等热化学近似。低频和气相带电簇有适用限制。不同组成体系不能混减绝对能量；相对配位复合物的关环势垒不是游离底物总势垒，单步TS不是完整催化循环或催化效率证据。

交付TS XYZ/PDB、截断/映射、虚频模式、IRC、端点和独立参考、输入输出/检查点清单、hash及可复核报告，区分通过/失败/未检验。遵守资源及并发预算；每轮记录再决定下一步。模型被否定时报告原因及范围改变选项，不无限迭代。用户要求停止时立即停止本任务计算和监测、保留结果；用户结束任务不等于科学验证通过。
