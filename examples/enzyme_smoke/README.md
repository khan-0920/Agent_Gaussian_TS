# Zn–His3 工程验证输入

这是已有 theozyme 假设的最小真实模型集成实例：2 个 160 残基骨架、每骨架 1 条序列、1 次受约束优化、RF3 独立回预测、每状态 2 个 PLACER 样本。模型实际随机行为可能受不同版本/编译/硬件影响，不承诺相同骨架或有候选通过。

`campaign.json` 明确使用稳定底物键图配合 TS-like 坐标，不是经过验证的过渡态模型。Rosetta `substrate.params` 来自此前工程预检，原子类型和部分电荷未经物理标定，只用于检查工具衔接。不要将 REU 或几何分数解读为催化能垒。原始来源和原子映射方法保存在 `source_provenance.json`。

`profile.json` 是 2026-10-19 guest 的实际环境路径，包含新版 RFD3 1.0.0 与独立 RF3 环境。迁移前复制并修改路径、GPU 和资源配置，不要覆盖其他任务的环境。

操作、失败恢复、筛选指标和支持范围见 [工具文档](../../docs/ENZYME_DESIGN.md)。运行目录应放在仓库忽略的 `campaigns/` 或独立数据盘，原始模型输出和权重不提交到 Git。
